- **PairedClient**, a new library, a device's side: `PairedServer` (one record a server: its id, name, TLS addresses, other paths and pins; `answers(as:)` refuses another server's id; `credentialAddresses` only over TLS, a pinned one only with pins, plain HTTP only on loopback; `merging(_:answeredAt:)` takes what a server says of itself only over TLS) and `PairedServers` (one record per server id); `ServerPaths` (addresses ranked by where the device is: loopback, its LAN, the tailnet, `.local`, the rest); `PathRace` (the first to answer, each next after a head start); `CertificatePins` (a certificate's SPKI and whole-certificate SHA-256s, read by a small DER walk, with no X.509 library); `PinnedSession` (Apple's systems: a URLSession that trusts the server's own certificate by its pins alone, for data, downloads, file uploads and WebSockets); `NetworkWatch` (the networks' changes, once they settle; the monitor's first report is not a change).
