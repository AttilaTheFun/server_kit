- **ServerTLS**, a new library. `TLSFront` ends TLS on every interface (SwiftNIO; IPv6 and IPv4, or IPv4's alone where there's no IPv6) with the pair `ServerCertificates` picks by the hello's SNI (a CA's for its names and whole-label suffixes, the server's own for the rest, an IP or no name included), and, once the handshake is done, hands the connection to the server's plain listener on loopback behind `SERVERKIT-TLS <secret>` and a PROXY v1 line. Limits: 256 connections, an optional cap from one address, a 10-second handshake, a 5-minute idle limit counting traffic either way, 1 MB held before the inner listener answers; back-pressure both ways; an optional log of refusals; async `start` and `stop` on a shared event-loop group; new certificates taken up by `use` without a restart. `ProxyV1` writes and parses the header (the secret compared in constant time, checked for strength at the start; addresses by family; ports without signs or leading zeros; bounded at 107 bytes), `ProxyV1.Reader` reads it as bytes come for any listener, and `ProxyV1Handler` does it in a SwiftNIO pipeline (loopback only, a timeout). `PEMPair.check(now:)` says whether a pair would serve. `TailscaleCertificate` (macOS and Linux) asks `tailscale cert` for a tailnet's pair, checks it, and keeps chain and key in one file (0600); a hung command is stopped, then killed.
